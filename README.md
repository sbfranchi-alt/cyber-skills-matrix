# IT to Cyber: Transferable Skills Matrix

An interactive page mapping common IT skills to CyberCX's cyber security practices,
for IT practitioners considering a move into cyber.

## What's inside
- What cyber security is, and the general skills a consultant needs
- A 0–3 matrix: 10 IT skills × 11 practices (IDAM, MSS, DFIR, STA, GRC, S&C, CS2, SIE, Secure AI, CCET, OTCS)
- A practice guide with solutions, suggested certifications and "good fit" profiles
- Best first moves, and links to the Academy, Cyber5050, AISA, AWSN, HerTechPath and more

## Using it
Hover the matrix to highlight a row and column, click a skill to see its best-fit
practices, and click a practice heading to jump to its details.

## Scoring
0 minimal · 1 useful · 2 strong · 3 direct carry-over. Totals are out of 30.
